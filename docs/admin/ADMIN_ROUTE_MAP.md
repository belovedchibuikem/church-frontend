# Canonical Admin Route Map

Frontend-only route graph. Source of truth: `lib/admin-routes.ts` plus `lib/admin-navigation.ts`. No Laravel/API operation is implemented by this map.

Shared URL state: `scope`, `tab`, `q`, `page`, `filter`, `status`, `date`, and `sort`. All catalog routes support direct refresh and deep links.
