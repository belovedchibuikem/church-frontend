# Known Gaps

This delivery is intentionally a complete frontend design implementation, not a backend product implementation.

- No Laravel work, API endpoints, database access, migrations, queues, mail delivery, payment processing, AI execution, or file generation is included.
- Create/edit/assignment/export/document/AI and protected-action surfaces are fully designed and can preserve local drafts or review notes. Authoritative privileged execution remains explicitly unavailable, and the UI never displays fake production success.
- Export, print, download, upload, and generated-document actions need a future authoritative file/API contract.
- Search, filter, pagination, complete tab workspaces, action drafts, module-return locations, and scope retention operate on fixture data or device-local/session state only.
- Local login/MFA pages demonstrate the intended route flow. The published private site uses the hosting platform’s real access gate.

These are deliberate frontend boundaries rather than unfinished screen-design defects.
